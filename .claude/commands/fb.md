要求：$ARGUMENTS

粉專網址、GB子 相簿、哪些 GB子 已經用過，都在 memory：`fb-page-posts.md`、`fb-gbko-photos.md`。先讀這兩個。

## 規則
- 使用者說過**不用先問就發**（11/17）。使用者直接貼了內文的，**原文照貼、不要改**；只有給方向的，照 `/promo` 的 FB 寫法自己寫。
- 每篇都附**一張新畫的說明圖**，上面要有 **GB子**（粉專看板娘，AI 生成）：
  - 說明圖每次重畫，不要拿 `docs/images` 的舊截圖充數。
  - **每張圖的 GB子 都要是不同的照片**，不可重複。用 `fb-gbko-photos.md` 清單裡還沒用過的，用完要更新清單。
  - 先掃一次相簿，使用者新加的照片也算沒用過。
  - 沒用過的用完了 → 把用過的**左右翻轉**再用（`flip:true`），每張只翻一次，從最早用的開始，記在清單的「Flipped used」。用掉最後一張沒用過的那次，回報裡要提醒使用者「從下一篇開始改用左右翻轉」。
  - 翻轉的也全用完了 → **不要發**，停下來提醒使用者往相簿加新的 GB子 照片。
  - 圖左下角標「JJptt 看板娘 GB子（AI 生成）」。
- 遇到 FB 要登入、驗證或任何看不懂的畫面：停下，請使用者自己在瀏覽器裡處理，不要替他輸入帳密。
- FB 跳「直接與用戶對話／新增按鈕」之類的推銷視窗：按「稍後再說」，不要加任何東西。

## 畫圖
**預設用復古風（11/20 起）**：`.claude/fb/retro.js` 的 `window.__jjRetro(o)`：左邊 GB子，右邊一個大的四階綠色螢幕，外面只有細細一圈灰色掌機框和小按鈕。`o.title`／`o.sub`，`o.sections:[{h, rows:[{k:'以前'|'現在', w:0-100, v:'3～4 秒'} 或 {tag:'爆', s:'範例標題'}]}]`。字用一般字體、放大、行距拉開，不要點陣字，不要多餘的框。範例標題一律虛構。

舊的粉紅對照圖：
`.claude/fb/panels.js` 定義 `window.__jjPanels(o)`：1080×1080，左邊 GB子、右上標題框、右邊上下兩格「以前／用 JJptt」三步驟對照。
- `o.gb`：GB子 原圖網址，或 `{src, r:[x,y,w,h]}`（拼貼照裡某一格，比例）；`o.flip:true` 左右翻轉。
- `o.L1`／`o.L2`：標題、副標。`o.top`／`o.bottom`：`{label, col, last:'bad'|'good', steps:[[第一行粗體, 第二行, 第三行], ×3]}`。
- 內容不適合對照圖時（例如工商其他專案），可以自己用 canvas 畫別的版面，GB子 一樣要在圖上。

## 發文步驟（內建瀏覽器 `mcp__Claude_Browser__*`）
1. `resize_window` 1280×900（太窄時 FB 只顯示左邊選單）；做完 `preset: desktop` 還原。
2. 取 GB子 原圖：在**同一個 tab** 開 `https://www.facebook.com/photo/?fbid=<id>`，取頁面上 naturalWidth 最大的 img 的 src，存進 `sessionStorage`（換頁 window 變數會不見；別的 tab 的 storage 拿不到）。
3. 回粉專首頁，把 `panels.js` 整段貼進 `javascript_tool` 執行，再呼叫 `__jjPanels` 產生 Blob。fbcdn 和 raw.githubusercontent.com 的圖都能畫進 canvas；本機檔案和其他網站 FB 不讓抓。
4. 點「在想些什麼？」開「建立貼文」，確認身分是 JJptt、分享對象「所有人」。focus 文字框後用 `computer` 的 `type` 打內文。
5. 附圖：把 Blob 包成 File，用 DataTransfer 放進對話框裡的 `input[type=file]`，觸發 change，等幾秒確認對話框裡有圖。
6. 按「繼續」→ 確認「所有人」「立即發佈」→ 按「發佈」。不要開加強推廣。
7. 重新開粉專，確認那篇只出現一次、有圖。然後更新 `fb-gbko-photos.md`。
- 每次 `javascript_tool` 不要超過約 40 秒（會逾時）：產生圖、打字、附圖、發佈分開做。
- 發文框附圖失敗：先發文字，再在那篇底下以 JJptt 身分留言補圖。

## 改舊貼文的圖
找該篇文字上方最近的「對JJptt的這則貼文採取的動作」按鈕（用位置找，不要往上找父元素，會抓到別篇）→「編輯貼文」→ **先確認對話框裡的文字是那篇** →「移除貼文附件」→ 放新圖 →「繼續」→「儲存」。

## 換封面
「編輯封面相片」旁邊頁面上第一個 `input[type=file]`（image）放 1640×624 的圖 →「儲存變更」。

## 排程
- 用 `CronCreate`（分鐘避開 :00、:30），prompt 寫清楚要發哪篇、照 `/fb` 的規則。
- **排程只在這個對話開著時有效**：電腦和 Claude 桌面 App 都要開著，關掉就不發；固定排程 7 天後自動失效。雲端排程登不進 FB，不能用。排之前要跟使用者講這點。
- 系列文：先把每篇的內文和圖的參數寫在一個檔案裡（每篇標 [ ]，發完改 [x] 加時間），排程每次發第一篇 [ ]，全部發完就 `CronDelete`。
