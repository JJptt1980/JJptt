# 說中文吧

從現在起，這個對話裡**所有**給使用者看的文字都用**台灣繁體中文**，直到使用者明確要求換語言。

- 包括：一般回覆、進度說明、問題、最後的總結、SendUserFile 的 caption、AskUserQuestion 的選項。
- 用台灣用語（程式碼、檔案、設定、網址、資料夾…），不要用簡體字或中國用語（代碼、文件、設置、網址鏈接、文件夾…）。
- 程式碼、指令、檔名、識別字、錯誤訊息原文保持原樣，不翻譯。
- 寫進 repo 的東西（commit message、程式註解）照那個專案原本的慣例，不受這個技能影響。
- 剛才若有用英文回覆，不必道歉或重講，接下來改用中文即可；使用者要求時才把上一則翻成中文。
